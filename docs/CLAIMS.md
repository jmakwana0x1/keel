# CLAIMS — what KEEL has claimed and stopped claiming

`docs/ARCHITECTURE.md` records how the mechanism was built. This file records what the product has **said**. Every row below is a claim that was made, then retracted. At least four were put back into pitch material after they were dead, rows 14 and 16 among them, because nothing in the repository said they were.

**Rule.** Before any figure or claim goes into the README or pitch material, check it against this file (CLAUDE.md rule 4). A retraction has to be as findable as the claim was (rule 8).

**How to read a row.** *Record* names the decision that retracted the claim, where one exists. Where none does, this file is the record. A figure in *What replaced it* traces to a committed file or carries a tag saying why it does not.
